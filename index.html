PARADIGM SHIFT · 範式轉移

為什麼說「工作流大於模型世代本身」？

從迷信單次提示參數量，走向推論時計算（Test-Time Compute）與迭代工程循環

🏋️

過去盲點：盲目擴展規模 (Scale)

單次前向傳遞 (Single Forward Pass)

迷信於零次提示（Zero-shot）下的智商評測。如同要求考生「一秒不打草稿直接寫出萬字論文」，極易因微小假設偏差而自圓其說地產生幻覺。

局限：單點擊穿率低、無法跨輪次自我糾錯
🚀

範式轉移：代理工作流 (Agentic Workflow)

推論時計算 (Test-Time Compute)

投入更多推論資源，透過「思考 ➔ 行動 ➔ 反省 ➔ 驗證」多輪迭代。如同提供草稿紙與計算機，讓模型在草稿中查缺補漏、步步為營。

吳恩達實證：GPT-3.5 + 工作流 ＞ 裸奔 GPT-4
文獻來源：Four Core Agentic AI Patterns (Andrew Ng, DeepLearning.AI, 2024)
TAXONOMY · 架構分水嶺

Anthropic 架構邊界：Workflow vs. Agent

釐清確定性代碼編排與模型自主控制流的本質邊界，杜絕盲目濫用

🔌

1. Augmented LLM

單次增強呼叫

單一請求中外掛 RAG 檢索、歷史對話上下文或特定工具，但僅執行一次前向預測。

比喻：帶著筆記進考場的學生
🛤️

2. Workflows (工作流)

代碼固化編排 (Code-orchestrated)

由確定性程式碼嚴密排定 LLM 串接順序；路徑固定、高度可預測、極易除錯與監控。

比喻：鋪設完備的高鐵鋼軌
🧭

3. Autonomous Agents

模型掌控控制流 (LLM-driven loop)

由 LLM 自主決定下一步該呼叫什麼工具、是否重試，完全動態探索未知狀態空間。

比喻：無人荒野中的全地形越野車
⚠️ Anthropic 工程警告：能用確定性高鐵軌道（Workflow）解決的業務，切勿盲目交給黑盒子自主代理（Agent）！
DESIGN PATTERNS · 四大戰略藍圖

吳恩達四大設計模式（The 4 Patterns）

將指數級空間的探索難題，降維為局部可控的四大系統解法

🪞

1. 自我反思 (Reflection)

先輸出草稿 ➔ 再自主批評

純模型內部自審，無需外部環境反饋即可挑出邏輯漏洞與筆誤。

比喻：交卷前自己重驗算
🧰

2. 工具調用 (Tool Use)

語意大腦 ➔ 外部確定性執行

精準符號運算與即時資訊獲取全面卸載給計算機與 API，消除數理幻覺。

比喻：愛因斯坦掏出計算機
🗺️

3. 長程規劃 (Planning)

宏觀目標 ➔ 有向無環圖 (DAG)

將未知複雜任務拆解為有序子步驟，並依據環境反饋動態修訂路線。

比喻：專業導遊遇雨改訂室內
👥

4. 多代理 (Multi-Agent)

專職角色 ➔ 對抗式驗收制衡

抑制單一 Prompt 注意力稀釋，分工專注並透過審查通訊協定提升系統魯棒性。

比喻：米其林廚房各司其職
架構本質：以系統控制迴圈打破 Transformer 單字自回歸的前進盲區
ENTERPRISE ARCHITECTURE · 工業實踐

Anthropic 工業界五大經典落地方案

高穩定度、模組化、低錯誤率的企業級 Agentic Workflow 骨架

🔗

1. 提示鏈 (Chaining)

將大任務切為串行線性子步驟，每步設硬性 Gate 門禁。

適用：流水線作業
🔀

2. 路由分流 (Routing)

意圖分類器前置判斷，分派至專屬微調模型或 Prompt。

適用：客服分流
⚡

3. 平行化 (Parallel)

包含任務切片（Sectioning）與多路並行投票（Voting）。

適用：安全護欄審查
🎯

4. 編排者-工作者

中央 Orchestrator 動態拆分未知子任務並派工彙整。

適用：複雜編程重構
🔄

5. 評估-優化循環

一端 Generator 產出，另一端 Evaluator 評判退修。

適用：高精度文書
💡 落地原則：從簡單模式（提示鏈、路由）開始構建，只有當確定性邏輯無法覆蓋邊界時，才解鎖高階模式。
ENGINEERING PRINCIPLE · 終極心法

系統工程終極心法：KISS 原則與學術自洽

Keep It Simple, Stupid —— 透明度、可除錯性與人機協同（Human-in-the-loop）

🛡️ Anthropic KISS 原則三大箴言

  • 1. 最簡優先： 永遠從最直覺的 Prompt 與代碼工作流開始，切勿過早追求複雜架構。
  • 2. 透明可除錯： 確保每一狀態節點的輸入輸出皆有完整日誌（Logging），可隨時追蹤歸因。
  • 3. 測試左移： 把邊界檢查往前移至純文字與 JSON 契約層，杜絕下游產出時的重大崩潰。

🎓 本作業之高階學術自洽

我們在作業九中所建構的 StateGraph 狀態機，完美融合了 Anthropic 的 **Evaluator-Optimizer** 與吳恩達的 **Reflection** 模式，以嚴格的 JSON 契約保證 100% 忠實度與零破版。

🌟 核心結論：AI 時代的卓越競爭力，在於系統架構工程的深度！
